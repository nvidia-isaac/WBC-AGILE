# AGILE v1.4.0

## Summary

This release adds support for Unitree H2Plus and includes minor improvements
and bug fixes.

## New features

- Added the `Velocity-H2-History-v0` training task for the Unitree H2Plus robot.

## Improvements

- Reduced offscreen video-rendering overhead by hiding environments that are
  not visible in the recording.
- Added smooth, configurable pose transitions to the joint-position debug GUI.
- Expanded gain-slider ranges when configured actuator gains exceed the
  default display limits.

## Bug fixes

- Corrected joint-to-actuator mapping for stiffness, damping, and effort limits
  in the joint-position debug GUI.
- Ensured training and application-startup failures return a nonzero exit code
  so CI and remote-training systems can detect failures reliably.

## Update notes

- This release is fully backward compatible with v1.3. No changes are required.
